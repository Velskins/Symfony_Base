# Cahier des charges - Bibliothèque de citations

## Objectif

Réaliser une application web permettant de constituer et gérer une bibliothèque de citations.

L'application doit être simple à utiliser, lisible et couvrir l'ensemble des fonctionnalités demandées.

---

## Fonctionnalités obligatoires

- [x] **Afficher la bibliothèque** : présenter l'ensemble des citations enregistrées dans une liste claire et lisible
- [x] **Afficher les informations d'une citation** : texte, auteur, source ou origine si elle est renseignée, date d'ajout et autres informations supplémentaires
- [x] **Ajouter une citation** : proposer un formulaire permettant de créer une nouvelle citation
- [x] **Contrôler les informations saisies** : les champs indispensables doivent être obligatoires et des messages compréhensibles doivent apparaître en cas de saisie incorrecte
- [x] **Consulter une citation** : proposer une page dédiée présentant la citation et toutes ses informations
- [x] **Modifier une citation** : permettre de corriger ou mettre à jour une citation existante
- [x] **Supprimer une citation** : permettre de retirer une citation de la bibliothèque
- [x] **Confirmer une suppression** : demander une confirmation avant la suppression définitive
- [x] **Gérer une bibliothèque vide** : afficher un message adapté lorsqu'aucune citation n'est disponible
- [x] **Navigation** : permettre de passer facilement entre la liste, l'ajout, la consultation et la modification
- [x] **Une fonctionnalité à développer (Créativité)**

---

## Contenu attendu pour une citation

- [x] Texte de la citation - *obligatoire*
- [x] Auteur - *obligatoire*
- [x] Source / origine - *facultative*
- [x] Date d'ajout - présente pour chaque citation - *obligatoire*
- [x] Autres données de votre choix (4 minimum obligatoires)
  - [x] Donnée 1 : Favoris
  - [x] Donnée 2 : Notes
  - [x] Donnée 3 : Langue
  - [x] Donnée 4 : Catégorie

---

## Présentation attendue

- [x] Les citations doivent être clairement séparées les unes des autres.
- [x] Les actions disponibles doivent être facilement identifiables : consulter, modifier et supprimer.
- [x] L'interface doit rester lisible sur l'ensemble des pages.
- [x] Le rendu visuel est libre, tant que l'application reste cohérente et utilisable.
